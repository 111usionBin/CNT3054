# 실제 실행한 비교 자료

`baseline_predictions.csv`, `baseline_metrics.csv`, `similarity.json`은 제공한 합성 문장에 대해 로컬에서 직접 계산한 결과입니다. NVIDIA LLM 결과는 포함하지 않습니다. 기본 API 스위치가 False이므로 학생이 키를 입력하고 실행해야 LLM 결과가 생성됩니다.

BERT의 이진 진단 12개 정확도 1.0은 의도적으로 만든 작은 예제의 결과이며 일반 성능이 아닙니다. 중립/혼합 4개에 대해 BERT는 이진 라벨을 강제로 출력하므로 이 부분의 원문을 별도로 확인하세요.
