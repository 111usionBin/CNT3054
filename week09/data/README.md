# 데이터 설명

`culture_reviews.csv`는 168개의 합성 영화 리뷰이다. 연기, 이야기 구성, 음악·음향, 촬영·미술 관련 문장을 조합했고, 두 영역을 섞은 문서도 포함했다. `build_sample.py`로 같은 자료를 다시 만들 수 있다. 실제 관객이나 특정 작품에 대한 조사 자료가 아니며 토픽이 비교적 잘 드러나도록 구성한 교육용 예시이다. 실제 수집 자료에서 같은 품질을 보장하지 않는다.

한 행은 리뷰 한 건이다. `review_id`는 예시 ID, `text`는 분석 텍스트, `source_type`은 합성 자료 표시이다. 코드는 선택한 텍스트 열만 학습한다. 정답 토픽이나 감정 라벨은 필요하지 않다. 토픽 번호에 정답 이름을 미리 붙이지 않는다.

`my_reviews_template.csv`에 한 행당 한 문서의 텍스트를 넣고 CSV UTF-8로 저장한다. 최소 5개 유효 문서가 필요하며, 토픽 해석에는 주제별 표현이 반복되는 충분한 양의 문서를 권장한다. 5개는 실행 최소 조건일 뿐 통계적 충분성의 기준이 아니다. 쉼표나 줄바꿈이 있는 텍스트는 CSV 편집 도구의 인용 규칙을 유지한다. 개인정보가 들어 있는 원문이나 조별 자료를 공개 저장소에 커밋하지 않는다.

`stopwords.txt`는 한 줄에 한 단어이다. 기본 전처리는 Kiwi의 일반명사·고유명사·외국어 토큰 중 두 글자 이상을 남긴다. 한 글자 단어, 동사·형용사가 빠지므로 의미가 달라질 수 있다. `tokens_preview.csv`를 보고 분석 목적에 맞게 수정한다. 기본 명사 설정은 감정분석에 쓰는 전처리와 다르다.
