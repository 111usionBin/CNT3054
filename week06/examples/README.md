# 실행 확인용 합성 예제 결과

제공된 CSV와 seed=42, requirements.txt의 고정 버전으로 실제 실행해 저장한 결과입니다.
테스트를 한 번 연 **교사용 예시 결과**이며 실제 관객 리뷰 연구의 성능이 아닙니다.
수업 중에는 먼저 검증 세트에서 판단한 뒤 자신의 최종 평가를 진행하세요.

CSV의 라벨은 0=부정, 1=긍정입니다. FP는 실제 부정을 긍정으로, FN은 실제 긍정을 부정으로 예측한 경우입니다.
`metrics.json`의 자료 SHA-256과 `data/synthetic_reviews.csv`를 비교하면 같은 자료인지 확인할 수 있습니다.
전체 예측, 계수, 그래프는 스크립트를 실행하면 `outputs/` 아래 새 폴더에 만들어집니다.
