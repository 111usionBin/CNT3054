# 합성 교육용 리뷰 데이터 카드

## 출처와 용도

`synthetic_reviews.csv`의 120개 문장과 라벨은 이 실습용으로 새로 작성한 합성 예제입니다.
실제 게시글을 인용하거나 수집하지 않았으며, 실제 작품·작성자를 식별하지 않습니다.
영화·드라마·공연·전시·웹툰 각 24개, 긍정 60개 / 부정 60개입니다.
문화콘텐츠에 대한 평가 방향을 분류하는 교육용 자료이며 실제 관객 반응 연구용 표본이 아닙니다.

## 라벨 기준

- `1`: 글쓴이가 해당 작품/관람 경험을 전체적으로 좋게 평가한다.
- `0`: 글쓴이가 해당 작품/관람 경험을 전체적으로 나쁘게 평가한다.
- 일부 “슬픈 결말인데도 훌륭했다” 같은 문장은 슬픔과 호평을 구분하는 교육용 예시다.
- 혼합 표현은 마지막 결론과 전체 문맥에서 지배적인 평가를 기준으로 교육용 라벨을 정했다.
- 중립 라벨은 없다. 애매한 실제 문장을 반드시 둘 중 하나로 강제하라는 뜻이 아니다.
- 교육용 의도 라벨이며 독립 평가자 간 신뢰도 연구를 수행한 데이터가 아니다.

## 열

| 열 | 의미 |
|---|---|
| `review_id` | 행의 고유 ID, SYN001–SYN120 |
| `group_id` | 같은 주제/구문을 대비하는 긍정·부정 예제쌍, PAIR001–PAIR060 |
| `domain` | 다섯 문화콘텐츠 영역 |
| `text` | 합성 한국어 문장 |
| `label` | 0 부정 / 1 긍정 |
| `source_type` | 모든 행이 synthetic_educational |

60개의 예제쌍을 그룹으로 분리해 서로 닮은 긍정/부정 문장이 학습과 평가 양쪽에 들어가지 않게 한다.
정규화된 완전 중복 문장도 제거한다. 그러나 공통된 감성 표현과 문체는 여전히 존재한다.
그룹 분리만으로 합성 데이터가 현실을 대표하게 되는 것은 아니다.
분리 알고리즘은 라벨 비율을 보존하려고 시도하되 같은 그룹을 절대 나누지 않는다.
seed=42에서 학습 72 / 검증 24 / 테스트 24개이고 각 분리의 두 라벨 수는 같다.

## 해석 제한

작은 크기, 인위적 클래스 균형, 반복 어휘, 같은 작성 방식, 장르의 제한 때문에 점수가 낙관적일 수 있다.
관객 모집단, 다른 플랫폼, 시간 변화, 다른 작품으로 일반화할 수 없다.
구문을 일부러 뒤집은 예제쌍은 사고 실험이며 실제 리뷰 발생 비율을 반영하지 않는다.
데이터를 바꾸거나 seed를 바꿔 높은 테스트 점수를 찾는 작업은 독립 성능 평가가 아니다.
