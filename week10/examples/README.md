# 기준 실행 결과

공개 예제 데이터로 실제 실행하여 저장한 결과다. 설정과 패키지 버전은 `run_metadata.json`에 있다. `interpretations_completed.json`과 그 Markdown 결과는 강의 제작자가 작성한 해석 예시다. `response_valid.json`과 `response_invalid.json`도 수동 작성한 검사 입력이며 LLM 실행 결과가 아니다.

학생의 실행 결과는 `outputs/`, 작성 기록은 `work/`에 저장한다. 기준 숫자를 맞추는 것보다 각자의 단어·원문·비중을 함께 읽는 데 초점을 둔다.
