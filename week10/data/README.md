# 데이터 구성
`concert_comments.csv`는 강의 제작자가 작성한 공연 예매·관람 합성 댓글 120개다. `build_sample.py`의 상황별 기본 문장과 맥락 문장을 조합했다. 외부 게시판을 수집하지 않았으며 개인정보는 없다.

|설계 상황|2026-09|2026-10|
|---|---:|---:|
|관람 비용|12|18|
|예매 운영|10|14|
|회원 선예매|8|32|
|무대 경험|10|16|
|합계|40|80|

날짜는 시기 비교를 위한 합성 값이다. 한 행은 하나의 댓글이며 `document_id`는 고정 식별자다. 모델은 `text`에서 추출한 명사 빈도만 사용한다. 상황별 설계 범주와 날짜는 LDA 입력 특성에 넣지 않는다. 모델의 토픽과 설계 범주가 항상 일치할 필요는 없다.

대표 문장에 맥락 문장을 더해 짧은 문서의 희소성을 줄였다. 반복 구조와 인위적인 구성 비율이 있으므로 실제 문화 현상·모집단·사건 효과의 근거로 사용하지 않는다. 원문 해석, 같은 토픽 안의 상반된 입장, 기간별 분모 차이를 학습하는 용도로 배포한다.

`stopwords.txt`에는 맥락에 공통적인 표현을 담았다. 예매·회원·가격처럼 질문에 중요한 표현은 남겼다. Kiwi 명사 추출에서는 원래 표현인 선예매가 예매 등으로 나뉠 수 있으므로 `tokens_preview.csv`와 원문을 함께 확인한다.
